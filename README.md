# Gestor de Tarefas

Pequena aplicação para gerir tarefas, feita com React + TypeScript + Tailwind CSS
como exercício de aprendizagem.

## Funcionalidades

- [ ] Adicionar tarefas
- [ ] Listar tarefas
- [ ] Marcar como concluída ou pendente
- [ ] Remover tarefas
- [ ] Filtrar por todas, pendentes e concluídas
- [ ] Mostrar o número de tarefas pendentes

> Âmbito da v1: tudo em memória, sem API, autenticação ou persistência.

## Tecnologias

React, TypeScript, Vite, Tailwind CSS

## Como correr

```bash
npm install
npm run dev
```
